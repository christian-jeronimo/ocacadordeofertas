🔥 Caçador de Ofertas

Aplicativo de uso do responsável pelo site

Caçador — Automações

Esta automação ajuda o responsável pelo Caçador de Ofertas a organizar cupons, publicar ofertas aprovadas e acompanhar o desempenho do site nas buscas do Google.

Como funciona

  • Rascunhos de cupons ficam em uma planilha privada e são publicados somente após aprovação do responsável.
  • Os dados de ofertas aprovadas são copiados para a planilha que alimenta o site.
  • Dados do Google Search Console são resumidos em abas privadas para orientar melhorias no site.

O aplicativo é operado pela conta Google autorizada pelo responsável. Visitantes do site não precisam conectar sua conta Google para consultar os cupons.

Veja a Política de Privacidade da automação para saber quais dados Google são acessados e como são usados.
